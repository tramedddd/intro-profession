# Сертификат GigaChat
Корневой сертификат скачан по HTTPS с официального адреса:
https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt

Он подключается только к GigaChat через `ca_bundle_file`.
Системное хранилище сертификатов не меняется; проверка HTTPS включена.
Документация: https://developers.sber.ru/docs/ru/gigachat/certificates

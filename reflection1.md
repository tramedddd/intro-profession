## Моя рефлексия
В первой работе создан ноутбук Python, который отправляет запрос в OMDb и выводит сведения о фильме из JSON.
Виртуальное окружение позволяет устанавливать библиотеки отдельно для проекта.
Основная версия хранится в master, а отдельная ветка используется для проверки изменений перед слиянием.
Примером такого изменения стал вывод актёров в movie-output-feature с последующим слиянием в master.
Коммиты сохраняют законченные этапы работы и позволяют проследить изменения кода.
Ключ API читается из локального файла .env, который исключён из Git, чтобы не раскрывать секретные данные.
JSON преобразуется в словарь Python, из которого программа извлекает название, год, жанр, режиссёра и рейтинг фильма.
AI-ассистент помог добавить обработку отсутствующего фильма, неверного ключа, таймаута и некорректного JSON, после чего эти сценарии были проверены.
До активации ключа OMDb возвращал ошибку 401, а после активации реальный поиск вернул Batman 1989 года.
Визуальная панель Git в VS Code позволяет просматривать изменения и выполнять коммиты; GigaCode в этой работе не использовался.
При повторном выполнении работы стоило бы сначала проверить ключ и подключение к API, а затем переходить к доработкам программы.

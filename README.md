## Практика 1
Откройте `rest_api_demo.ipynb` в VS Code с расширениями Python и Jupyter.
Создайте окружение: `python -m venv .venv`, выберите его ядром ноутбука,
затем установите библиотеки: `python -m pip install -r requirements.txt`.
В Windows активация окружения: `.venv\Scripts\Activate.ps1`.
Получить личный ключ: https://www.omdbapi.com/apikey.aspx
Ключ вводится через getpass; в коммиты и вывод ячеек он не попадает.

## Запуск в Windows
Установите Python 3.12+ и VS Code с расширениями Python и Jupyter.
В терминале папки проекта:
```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```
Если `.env` уже существует, не перезаписывайте его. Заполните локально
OMDB_API_KEY и GIGA_KEY. В VS Code выберите `.venv` ядром ноутбуков.
Сам файл `.env` не публикуется. В `.env.example` секретов нет.
Для GigaChat подключён официальный сертификат из папки certs; проверка TLS включена.
Endpoint можно изменить переменной GIGACHAT_BASE_URL.

Откройте ноутбук и выполните ячейки сверху вниз. В llm_work.ipynb сохранены
результаты настоящего API-прогона; по умолчанию он показывает эти результаты
без новых запросов. Для нового замера установите RUN_API=True.
CLI для нового базового замера: `python rental_llm.py`.
Для расширенного замера сначала переключитесь в llm-improve-2,
затем запустите `python rental_llm.py --advanced`.

## Проверенные результаты и ограничения
GigaChat-2, temperature=0: количество людей определено верно в 15 из 15 заявок
(100%). Исходные заявки и ответы сохранены в results/rental_with_results.csv.
Расширенная техника на llm-improve-2 дала 73,3% по количеству людей и 64,0%
в среднем по пяти дополнительным полям; вывод JSON оказался сложнее базовой задачи.
Подробности, невалидные ответы и ошибки дат/цен сохранены в этой ветке.

14 автоматических тестов проходят в расширенной ветке; в базовой доступны
8 тестов OMDb. Запуск из корня: `python -m unittest discover -s tests -v`.
Тесты OMDb используют явные тестовые ответы, а не выдают их за реальный запрос.
После активации личного ключа выполнены реальные запросы к OMDb: найден
Batman (1989), корректно обработаны отсутствующий фильм и неверный ключ.
Ответ сервиса и отчёт сохранены в results/omdb_batman.json и
results/omdb_validation.json. Ноутбук rest_api_demo.ipynb выполнен сверху вниз
с настоящим запросом; ключ в выводах и Git отсутствует.
По умолчанию название фильма вводится с клавиатуры; для автоматического запуска
можно задать OMDB_MOVIE_TITLE. Получить личный ключ:
https://www.omdbapi.com/apikey.aspx

Обзор выполнен Codex, а не GigaCode; это прямо отмечено в CODE_REVIEW.md.

# Правила разметки варианта 18
- Нумерация `id` соответствует порядку строк CSV, начиная с 1.
- `count` взят из исходного `amount`; остальные поля размечены по текстам заявок.
- Животные не входят в число людей; без упоминания детей `count_children = 0`.
- «Для двоих» и «двухместный номер» без детей считаются двумя взрослыми.
- При диапазоне заезда берётся ранняя дата. Без года: `--MM-DD`; без месяца: `null`.
- `nights` — разность дат выезда и заезда; «на N дней/суток» принимается за N ночей.
- Из диапазона длительности берётся максимум. «Не менее недели» принимается за 7 ночей.
- `price_per_day` — максимум цены в рублях за всё жильё в сутки; цену за человека умножаем на число людей.
- Отсутствующее числовое значение обозначается `null`.
- `remarks` содержит пожелания из текста и не оценивается точным совпадением.

Точность каждого поля: число совпадений с эталоном / 15. Средняя точность
дополнительных полей — среднее по `count_adults`, `count_children`, `start_date`,
`nights`, `price_per_day`. Невалидный ответ считается ошибкой по всем полям строки.

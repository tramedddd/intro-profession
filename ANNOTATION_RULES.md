# Правила ручной разметки варианта 18

Эталон количества людей взят из `amount` исходного CSV. Дополнительные поля
размечены вручную по текстам; они не являются готовыми ответами LLM.
Нумерация `id` соответствует порядку 15 строк CSV, начиная с 1.
Разметка фиксируется перед экспериментом. Модель получает только текст заявки.

- `count_adults` и `count_children` — люди, без домашних животных.
  «Для двоих», «на 2х человек», «двухместный номер» без упоминания детей
  трактуются как два взрослых. Это условность оценки, а не гарантированный факт.
- Без упоминания детей ставим 0. «На одного человека» — один взрослый.
- `start_date` — наиболее ранний заезд из диапазона. Без года формат `--MM-DD`;
  при явно указанном годе — `YYYY-MM-DD`. Год 2026 из даты выполнения
  работы не переносится в исторические заявки.
- В строке 6 «с 20–22» отсутствует месяц: дата `null`, хотя число ночей известно.
- `nights` при двух датах — разность выезда и заезда. «На N дней/суток»
  для оценки принимаем за N ночей. «Неделька» — 7. Диапазон длительности — максимум.
- В строке 4 «не менее чем на неделю» не имеет максимума: фиксируем нижнюю
  границу 7 и сохраняем оговорку в `remarks`. Это явно выбранное правило оценки.
- `price_per_day` — рубли за всё жильё за сутки. Верхняя граница или максимум
  диапазона. В строке 9: 2000 за номер или 500 × 4 человека, то есть 2000.
  «Бюджетно», «эконом» без суммы не превращаются в придуманную цену: `null`.
- `remarks` — свободный текст о пожеланиях; его не оцениваем точным совпадением.

Для каждого из пяти дополнительных полей точность равна числу точных
совпадений / 15. Средняя — среднее этих пяти точностей. Отдельно показываем
точность `count` и среднюю по всем шести числовым/датовым показателям.
Неудачный запрос или невалидный JSON считается ошибкой по всем полям этой строки.
`null` в успешном ответе совпадает с эталонным `null`. Пустые поля не удаляются
из знаменателя. При полном отсутствии подключения качество не оценивается.

Разметка подготовлена с помощью Codex и доступна для проверки студентом;
личная проверка студентом не заявляется как уже выполненная.

# Проверка кода первой работы
Проверка выполнена Codex 12.11.2026. GigaCode не запускался.

Добавлены таймаут HTTP, проверка пустого ввода, обработка неверного ключа,
отсутствующего фильма и некорректного JSON. Сообщения ошибок не содержат
URL запроса с ключом. HTTPS включён, ключ остаётся в локальном `.env`.

Автопроверка: `python -m unittest discover -s tests -p "test_movie_api.py" -v`.
Тестовые ответы OMDb подменяются явно через Mock. Такие тесты проверяют
обработку ошибок; реальное обращение к OMDb требует личного API-ключа.
На этапе подготовки личного ключа OMDb не было, успешный живой запрос
к OMDb не заявляется как выполненный.
